# Contributing

Thank you for your interest in contributing to this project.

## Contribution Areas

You can contribute by improving:

1. D365FO X++ design.
2. Dataverse schema design.
3. Power Automate or Azure Function integration patterns.
4. Adyen API payload examples.
5. Webhook processing documentation.
6. Security and PCI considerations.
7. Testing scenarios and sample data.

## Guidelines

1. Keep changes focused and easy to review.
2. Avoid storing credentials, API keys, secrets, or customer-specific data.
3. Use clear naming for D365FO objects, Dataverse tables, and sample payloads.
4. Document any assumptions clearly.
5. Make sure samples use fictional data only.

## Disclaimer

This project is not an official Microsoft or Adyen product. Contributions should be reviewed and tested before use in production environments.
